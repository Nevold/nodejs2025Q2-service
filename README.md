# Home Library Service

## Downloading

```
git clone {repository URL}
```

## Installing NPM modules

```
npm ci
```

## Running application

```
npm run start
```

or

```
npm run start:dev
```

## Running application with Docker

```
npm run docker:up
```

## Testing

To run all test with authorization

```
npm run test:auth
```

```
npm run test:refresh
```
